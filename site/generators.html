Generators

Three commands create the building blocks of a module: make:module for the module itself, make:dto for a Data class and make:action for one business operation. For a full CRUD, see CRUD.

  • Rules every generator follows
  • make:module
  • make:dto

  • Naming

Rules every generator follows

  • They need a profile with modules (modular, saas or tenant-saas). With no profile or with basic they refuse.
  • Everything is rendered and checked in memory first. If a check fails, nothing is written.
  • They never overwrite. An existing file or module (compared case-insensitively) is a refusal.
  • Names are converted to StudlyCase (orders becomes Orders), and the command prints the name it used.
  • Use the commands. Do not copy or fill stubs by hand.

make:module

$ php artisan make:module Orders --api --web

make:module Orders --api --web

  • Generated app/Modules/Orders/Provider.php, registered in bootstrap/providers.php.
  • Generated routes/api.php (with --api, loaded with the api group and the /api prefix) and routes/web.php (with --web, loaded with the web group).
  • Refused when the module exists, the name is invalid, or --central is used outside tenant-saas.

See also: make:module options

With neither flag you get only Provider.php; add route files later by hand, loading them in Provider.php the same way. The module folder is blueprint.module_path (default app/Modules). Cached config and routes are cleared.

In tenant-saas, module routes use the tenant middleware group. Pass --central for a platform module whose routes answer only on central domains and whose route names start with central.. See Tenancy.

Put module-wide middleware, such as auth:sanctum for a token API, on the route groups in Provider.php.

make:dto

$ php artisan make:dto Orders OrderData --fields="name:string,quantity:int,note:?string"

Writes app/Modules/Orders/Data/OrderData.php: a final readonly class whose constructor declares one public property per field. Without --fields the constructor is empty, with a commented example.

--fields partMeaning
name:stringComma-separated name:type pairs. Names become camelCase properties.
string, int, float, bool, arrayScalar and array types
Carbon\CarbonImmutableAny fully qualified class name; it is imported
?stringA leading ? makes the property nullable

Refused: a missing type, an unknown type, an invalid or duplicate name, a stray comma, or the module not existing. If the class name does not end in Data, the command suggests one that does.

make:action

$ php artisan make:action Orders CancelOrder --data=OrderData --transaction

make:action Orders CancelOrder --data=OrderData --transaction

  • Generated app/Modules/Orders/Actions/CancelOrder.php with handle(OrderData $data): void, its body wrapped in DB::transaction.
  • Refused when OrderData is not in app/Modules/Orders/Data/. Data classes must come from the same module.
  • Note A name ending in Action gets a tip: the folder already says it (CancelOrder, not CancelOrderAction).

See also: make:action options · make:dto options

Naming

Use short, common English words. Code should be easy to read for developers whose first language is not English.

KindGoodAvoid
ActionCreateOrder, CancelOrderExecuteOrderCreationWorkflow
DataOrderDataOrderPayloadTransferObject
QueryListOrdersOrderPersistenceOrchestrationManager
Methodhandle(), cancel(), find()performOrderMutation()
  • Prefer one or two words. No unclear abbreviations.
  • Singular for one record (Order), plural for collections (ListOrders).
  • Do not repeat the folder name in the class name without a reason.

Customizing stubs

The generated code comes from stubs. To change it, publish them:

$ php artisan vendor:publish --tag=blueprint-stubs

They are copied to stubs/blueprint/ and used automatically. To keep them elsewhere, set blueprint.stub_path. A stub is looked up in stub_path, then stubs/blueprint/, then the package.

Broken stubs are refused. A stub that leaves a {{ placeholder }} unfilled, no longer declares the expected class, drops ->names('api.{{ uri }}') from route.stub, or would drop a requested feature gate stops the command before anything is written.
