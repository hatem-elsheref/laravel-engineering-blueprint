Getting started

A Laravel 12 and 13 package (PHP 8.3+) that turns one engineering standard into working code: profiles, module and CRUD generators for Blade pages and JSON APIs, multi-tenancy, features, settings and translations.

  • Install
  • Or start a new app
  • Your first CRUD
  • What you got

Install

In an existing Laravel 12 or 13 app:

$ composer require best/laravel-engineering-blueprint
$ php artisan engineering:install --profile=modular

The profile decides what the app gets: basic, modular, saas or tenant-saas. Not sure? Start with modular; you can move up later. See Profiles.

Check the environment and the recorded profile at any time:

$ php artisan engineering:about

Or start a new app

From a clone of the repository, one command builds a fresh app with the package, Pest, your profile and languages, migrations, and an example module whose generated tests pass:

$ bin/new-app ~/Sites/shop --profile=saas --locales=en,ar

Your first CRUD

$ php artisan make:module Orders --api --web
$ php artisan make:crud Orders Order --api --web --fields="name:string,quantity:int,note:?string"
$ php artisan migrate
$ php artisan test --filter="OrderApiTest|OrderWebTest"

make:crud Orders Order --api --web

Writes the model, migration, factory, Store/Update requests, OrderData, the CreateOrder, UpdateOrder and DeleteOrder actions, the ListOrders query and OrderPolicy, then both sides:

  • Generated JSON API: OrderController, OrderResource, routes api.orders.*, Pest API tests.
  • Generated Blade pages: OrderPageController, five views, routes orders.*, Pest web tests.
  • Refused before anything is written when a file already exists, a name is reserved or a stub is out of date.

See also: CRUD: Blade & API · make:crud options

What you got

RequestAnswer
GET /orders in a browserThe list page (signed-in users)
GET /api/ordersJSON, paginated
Any page as a guest403: the generated policy denies guests

Tighten the policy. OrderPolicy lets every signed-in user do everything. Change it before going live, and add a login (Breeze, Jetstream or your own) for the Blade pages.
