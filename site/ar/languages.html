اللغات

تترجم الحزمة الواجهة: صفحات Blade المولّدة ورسائل الحزمة نفسها. لا تترجم بياناتك، فتخزين السجلات بعدة لغات مسؤولية تطبيقك.

  • ضبط اللغات
  • كيف تُختار لغة الطلب
  • مبدّل اللغة
  • التخطيط من اليمين إلى اليسار
  • ترجمة النصوص

ضبط اللغات

// config/blueprint.php
'locales' => ['en', 'ar'],                  // languages the app serves
'rtl_locales' => ['ar', 'fa', 'he', 'ur'],  // shown right-to-left

القيمة الافتراضية لـ locales هي ['en']. اللغة الافتراضية للتطبيق هي app.locale في Laravel (APP_LOCALE)، كما هي مضبوطة عند إقلاع التطبيق.

كيف تُختار لغة الطلب

يُضاف الوسيط SetLocale إلى المجموعتين web وapi. لا تُقبل إلا اللغات الموجودة في blueprint.locales، وأول تطابق هو الذي يُعتمد.

الترتيبطلبات API (JSON أو /api/*)طلبات الويب
1الترويسة Accept-Language، حسب قيمة الجودةاختيار الزائر، المخزّن في الجلسة عبر /locale/{locale}
2الإعداد app.language (في saas وtenant-saas، وفي tenant-saas داخل مستأجر فقط)
3اللغة الافتراضية للتطبيق (app.locale)

تُضبط اللغة في كل طلب، فلا تحتفظ العملية العاملة طويلة الأمد بلغة الطلب السابق أبدًا.

مبدّل اللغة

تسجّل الحزمة GET /locale/{locale} باسم blueprint.locale في مجموعة web. يخزّن اللغة في الجلسة ويعيد التوجيه إلى الصفحة السابقة. اللغة غير الموجودة في blueprint.locales تعيد 404.

<a href="{{ route('blueprint.locale', 'ar') }}">العربية</a>

التخطيط المولّد يعرض هذه الروابط تلقائيًا عندما تكون هناك أكثر من لغة مُعدّة.

التخطيط من اليمين إلى اليسار

التخطيط الذي ينشئه make:crud --web (resources/views/layouts/blueprint.blade.php) يضبط <html lang dir> حسب اللغة الحالية: dir="rtl" للغات الموجودة في rtl_locales، وltr لغيرها.

صفحات الأخطاء. صفحات أخطاء Laravel (403، 404، …) تعرض عناوين مترجمة لكنها تستخدم تخطيط Laravel الخاص مع <html lang="en">. لصفحات أخطاء من اليمين إلى اليسار، شغّل php artisan vendor:publish --tag=laravel-errors واضبط lang وdir في resources/views/errors/layout.blade.php بالطريقة التي يتبعها تخطيط الحزمة.

ترجمة النصوص

  • الصفحات المولّدة ورسائل الحزمة تستخدم __() بمفاتيح إنجليزية.
  • تأتي الحزمة مع lang/ar.json فيه الترجمة العربية لنصوصها: أزرار مثل Save وDelete، ورسائل حالة مثل ":item created." و"This feature is not enabled."، ورسالة Laravel "This action is unauthorized." وعناوين صفحات الأخطاء.
  • make:crud --web يضيف اسم الكيان وأسماء الحقول (مثل "Order" و"Orders" و"Quantity") إلى lang/<locale>.json لكل لغة مُعدّة غير en، والنص الإنجليزي قيمةً لها. الترجمات الموجودة تبقى كما هي. ترجم القيم الجديدة.
  • لرسائل التحقق في Laravel، شغّل php artisan lang:publish وأضف lang/ar/validation.php.

إضافة لغة

  1. أضف رمز اللغة إلى blueprint.locales، مثل ['en', 'ar', 'fr']. إذا كانت تُكتب من اليمين إلى اليسار وليست مدرجة مسبقًا، فأضفها إلى rtl_locales.
  2. أنشئ lang/fr.json وترجم نصوصك. نصوص الحزمة التي لا ترجمة لها تظهر بالإنجليزية.
  3. شغّل make:crud --web كالمعتاد، فتُضاف مفاتيح الكيانات الجديدة إلى lang/fr.json. الكيانات المولّدة قبل إضافة اللغة تحتاج إلى إضافة أسمائها يدويًا.
  4. يمكنك اختياريًا ضبط الإعداد app.language لكل مستأجر بالأمر php artisan setting:set app.language fr (أضف --tenant=acme في tenant-saas).

للتطبيق الجديد، يضبط bin/new-app اللغات نيابة عنك. أول لغة تصبح الافتراضية (APP_LOCALE):

$ bin/new-app ~/Sites/shop --profile=saas --locales=en,ar
