الترقية

كيف تنتقل إلى إصدار جديد من best/laravel-engineering-blueprint، وما الذي تغيّر بين 0.x و1.0. الترقية لا تغيّر أبدًا الكود الذي ولّدته سابقًا، وإنما يتبع ناتج make:* الجديد وحده القواعد الجديدة.

المتطلبات

الاعتماديةالمدعوم
PHP8.3 أو أحدث (التكامل المستمر يختبر 8.3 و8.4)
Laravel12 و13
stancl/tenancy^3.10، للنمط tenant-saas فقط

php artisan engineering:about يطبع الإصدار المثبّت ويفحص بيئتك مقابل هذه الحدود الدنيا.

خطوات أي ترقية

  1. حدّث الحزمة: 
    $ composer update best/laravel-engineering-blueprint
  2. اقرأ القسم الخاص بالإصدار الذي تنتقل إليه أدناه.
  3. إذا نشرت القوالب في stubs/blueprint/، فقارنها بقوالب الحزمة الجديدة. احفظ نسخة من تعديلاتك، ثم استبدلها بالأمر: 
    $ php artisan vendor:publish --tag=blueprint-stubs --force
  4. امسح الذاكرة المؤقتة وشغّل اختباراتك: 
    $ php artisan optimize:clear
$ php artisan test

القوالب المنشورة بعد الترقية

  • مرفوض القالب القديم (عنصر نائب غير مملوء، أو صنف مفقود، أو غياب ->names('api.{{ uri }}')، أو بوابة ميزة محذوفة) يوقف المولّد برسالة تذكر اسم القالب. لا يُكتب شيء.
  • ملاحظة أصلح القالب أو احذفه، ثم أعد تشغيل الأمر.

من 0.x إلى 1.0

معظم تطبيقات 0.x تُرقّى بلا تغييرات. افحص هذه النقاط:

المجالما الذي تغيّرماذا تفعل
أسماء مسارات APImake:crud يسمّي مسارات API بـ api.<uri>.*، وصفحات الويب تستخدم <uri>.*. مسارات API الأقدم اسمها <uri>.*.لا شيء للمسارات الموجودة. قبل إضافة صفحات ويب (make:crud … --web) لكيان مسار API الخاص به بلا اسم، أضف ->names('api.<uri>') إلى ذلك المسار. يخبرك الأمر إذا كان الاسم مستخدمًا.
route.stub المنشوريجب أن يحتفظ بـ ->names('api.{{ uri }}').أعد نشره أو أضف الاستدعاء.
config/blueprint.phpمفاتيح جديدة: layout، locales، rtl_locales، tenant_seeder، tenant_domain. القيمة الافتراضية لـ features وsettings أصبحت null (تُشتق من shared_path).انسخ المفاتيح الناقصة من إعدادات الحزمة، أو شغّل php artisan engineering:install --force (يحتفظ بنمطك، ويُحفظ الملف القديم بكل تعديلاتك الأخرى باسم config/blueprint.php.bak). في الحالتين، تعود المفاتيح الناقصة إلى قيم الحزمة الافتراضية وقت التشغيل.
حقول المصفوفاتقواعد جديدة: بحد أقصى 100 عنصر، كل منها نص لا يتجاوز 255 حرفًا.الطلبات المولّدة في 0.x تحتفظ بقواعدها. شدّدها يدويًا إن أردت الحماية نفسها.
جلسات tenant-saasجلسات الويب مرتبطة بالمستأجر (أو التطبيق المركزي) الذي بدأت فيه، وفي غيره تحصل على 403.لا شيء. المستخدمون المسجَّل دخولهم في مستأجر يسجّلون الدخول من جديد في مستأجر آخر.
التخزين المؤقت في tenant-saasالتخزين المؤقت للمستأجر يحتاج إلى مخزن يدعم الوسوم.اضبط CACHE_STORE=redis (أو memcached).
الإعداد app.languageالتعريف المولّد أصبحت قيمته الافتراضية config('app.locale').اختياري: غيّر 'default' => 'en' في app/Shared/Settings/Settings.php.
اللغاتالصفحات المولّدة تستخدم __().لمزيد من اللغات، اضبط 'locales' => ['en', 'ar'] في config/blueprint.php وترجم lang/<locale>.json. راجع اللغات.
