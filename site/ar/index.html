البداية

حزمة لـ Laravel 12 و13 (PHP 8.3+) تحوّل معيارًا هندسيًا واحدًا إلى كود يعمل: أنماط، ومولّدات للوحدات وCRUD لصفحات Blade وواجهات JSON API، وتعدد المستأجرين، والميزات، والإعدادات، والترجمات.

التثبيت

في تطبيق Laravel 12 أو 13 قائم:

$ composer require best/laravel-engineering-blueprint
$ php artisan engineering:install --profile=modular

النمط يحدد ما يحصل عليه التطبيق: basic أو modular أو saas أو tenant-saas. لست متأكدًا؟ ابدأ بـ modular، ويمكنك الانتقال إلى نمط أعلى لاحقًا. راجع الأنماط.

افحص البيئة والنمط المسجَّل في أي وقت:

$ php artisan engineering:about

أو ابدأ تطبيقًا جديدًا

من نسخة مستنسخة من المستودع، يبني أمر واحد تطبيقًا جديدًا فيه الحزمة وPest ونمطك ولغاتك والترحيلات، ووحدة مثال تنجح اختباراتها المولّدة:

$ bin/new-app ~/Sites/shop --profile=saas --locales=en,ar

أول CRUD

$ php artisan make:module Orders --api --web
$ php artisan make:crud Orders Order --api --web --fields="name:string,quantity:int,note:?string"
$ php artisan migrate
$ php artisan test --filter="OrderApiTest|OrderWebTest"

make:crud Orders Order --api --web

يكتب النموذج، والترحيل، والمصنع، وطلبَي Store/Update، وOrderData، والإجراءات CreateOrder وUpdateOrder وDeleteOrder، والاستعلام ListOrders وOrderPolicy، ثم الجانبين:

  • أُنشئ واجهة JSON API: OrderController وOrderResource، والمسارات api.orders.*، واختبارات Pest للواجهة.
  • أُنشئ صفحات Blade: OrderPageController، وخمسة قوالب عرض، والمسارات orders.*، واختبارات Pest للويب.
  • مرفوض قبل كتابة أي شيء إذا كان أحد الملفات موجودًا، أو كان الاسم محجوزًا، أو كان أحد القوالب (stub) قديمًا.

الطلبالاستجابة
GET /orders في المتصفحصفحة القائمة (للمستخدمين المسجَّل دخولهم)
GET /api/ordersJSON مقسَّم إلى صفحات
أي صفحة لزائر غير مسجَّل403: السياسة المولّدة ترفض الزوار

شدّد السياسة. OrderPolicy تسمح لكل مستخدم مسجَّل دخوله بفعل كل شيء. عدّلها قبل الإطلاق، وأضف تسجيل دخول (Breeze أو Jetstream أو حلك الخاص) لصفحات Blade.
