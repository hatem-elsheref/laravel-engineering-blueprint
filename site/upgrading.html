Upgrading

How to move to a new version of best/laravel-engineering-blueprint, and what changed between 0.x and 1.0. Code you already generated is never changed by an upgrade; only new make:* output follows the new rules.

  • Requirements
  • Steps for any version
  • 0.x to 1.0
  • Versions

Requirements

DependencySupported
PHP8.3 or later (CI runs 8.3 and 8.4)
Laravel12 and 13
stancl/tenancy^3.10, only for the tenant-saas profile

php artisan engineering:about prints the installed version and checks your environment against these minimums.

Steps for any version

  1. Update the package: 
    $ composer update best/laravel-engineering-blueprint
  2. Read the section for your target version below.
  3. If you published stubs to stubs/blueprint/, compare them with the new package stubs. Back up your edits, then overwrite them with: 
    $ php artisan vendor:publish --tag=blueprint-stubs --force
  4. Clear caches and run your tests: 
    $ php artisan optimize:clear
$ php artisan test

Published stubs after an upgrade

  • Refused A stale stub (unfilled placeholder, missing class, missing ->names('api.{{ uri }}'), dropped feature gate) stops the generator with a message naming the stub. Nothing is written.
  • Note Fix or delete the stub, then re-run the command.

See also: Customizing stubs

0.x to 1.0

Most 0.x apps upgrade without changes. Check these points:

AreaWhat changedWhat to do
API route namesmake:crud names API routes api.<uri>.*; web pages use <uri>.*. Older API routes are named <uri>.*.Nothing for existing routes. Before adding web pages (make:crud … --web) for an entity whose API route is unnamed, add ->names('api.<uri>') to that route. The command tells you if a name is taken.
Published route.stubMust keep ->names('api.{{ uri }}').Re-publish it or add the call.
config/blueprint.phpNew keys layout, locales, rtl_locales, tenant_seeder, tenant_domain. features and settings default to null (derived from shared_path).Copy the missing keys from the package config, or run php artisan engineering:install --force (keeps your profile; the old file, with any other edits, is saved as config/blueprint.php.bak). Missing keys fall back to the package defaults at runtime either way.
Array fieldsNew rules: at most 100 elements, each a string up to 255 characters.Requests generated by 0.x keep their rules. Tighten them by hand if you want the same protection.
tenant-saas sessionsWeb sessions are tied to the tenant (or central app) where they started; elsewhere they get 403.Nothing. Users signed in on one tenant sign in again on another.
tenant-saas cacheTenant cache needs a store with tags.Set CACHE_STORE=redis (or memcached).
app.language settingThe generated definition now defaults to config('app.locale').Optional: change 'default' => 'en' in app/Shared/Settings/Settings.php.
LanguagesGenerated pages use __().For more languages, set 'locales' => ['en', 'ar'] in config/blueprint.php and translate lang/<locale>.json. See Languages.
