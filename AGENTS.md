# This repository

**Laravel Engineering Blueprint** — portable kit (docs, skills, rules, stubs), not a Laravel app.

When editing this repo:

- **Phase 0 authority:** `docs/PHASE-0.md` and the five specs; amend there first, then sync `rules.md` if needed.
- Keep `rules.md` as narrative; approved design lives in `docs/*.md`.
- Skills live in `kit/skills/`; stubs in `kit/stubs/`.
- Run `./bin/leb-install /path/to/laravel-app --link-agents` to test installs.

For Laravel application work in another project, install the kit there and follow that project's `AGENTS.md`.
