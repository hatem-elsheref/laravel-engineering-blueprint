# make:crud (Phase 5, API) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make:crud <Module> <Entity> [--fields=...]` generates a working, tested JSON API CRUD inside an existing module, refusing safely and rolling back on failure.

**Architecture:** Pure helpers do all decisions — `CrudField`/`CrudFields` (per-type mapping, CRUD limits), `CrudNames` (every derived name and path), `RouteFile` (append `use` + route line). `MakeCrudCommand` runs gates → collisions → renders every file to memory via `StubRenderer` → validates → writes with rollback → appends route. `PestDetector` (container-bound) decides whether the test file is written.

**Tech Stack:** PHP 8.3, Laravel 12 + 13, Testbench ^10 || ^11, Pest 4.

**Spec:** `docs/superpowers/specs/2026-11-03-make-crud-design.md`

## Global Constraints

- Refusal = exit 1, nothing written, `routes/api.php` unchanged. Messages exactly as spec §5.
- Generated files: `declare(strict_types=1);`, 4-space indent, trailing newline, imports sorted alphabetically, no blank import block when empty.
- Phase 3–4 command behavior and tests unchanged.
- Done = `vendor/bin/pest` green on Laravel 13 and 12, output shown.

<?php

declare(strict_types=1);

namespace App\Modules\Orders\Data;

use App\Modules\Orders\Requests\StoreOrderRequest;
use App\Modules\Orders\Requests\UpdateOrderRequest;

final readonly class OrderData
{
    public function __construct(
        public string $name,
        public int $quantity,
        public ?string $note,
    ) {}

    public static function fromRequest(StoreOrderRequest|UpdateOrderRequest $request): self
    {
        return new self(
            name: $request->string('name')->toString(),
            quantity: $request->integer('quantity'),
            note: $request->validated('note') === null ? null : $request->string('note')->toString(),
        );
    }

    /**
     * @return array<string, mixed>
     */
    public function toArray(): array
    {
        return [
            'name' => $this->name,
            'quantity' => $this->quantity,
            'note' => $this->note,
        ];
    }
}

use Illuminate\Foundation\Http\FormRequest;

final class StoreOrderRequest extends FormRequest

    public function authorize(): bool

        return [

            'note' => ['nullable', 'string', 'max:255'],
        ];
    }

```php
<?php

declare(strict_types=1);

namespace App\Modules\Orders\Controllers;

use App\Modules\Orders\Actions\CreateOrder;
use App\Modules\Orders\Actions\DeleteOrder;
use App\Modules\Orders\Actions\UpdateOrder;
use App\Modules\Orders\Data\OrderData;
use App\Modules\Orders\Models\Order;
use App\Modules\Orders\Queries\ListOrders;
use App\Modules\Orders\Requests\StoreOrderRequest;
use App\Modules\Orders\Requests\UpdateOrderRequest;
use App\Modules\Orders\Resources\OrderResource;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Resources\Json\AnonymousResourceCollection;
use Illuminate\Http\Response;
use Illuminate\Support\Facades\Gate;

final class OrderController
{
    public function index(ListOrders $query): AnonymousResourceCollection
    {
        Gate::authorize('viewAny', Order::class);

        return OrderResource::collection($query->handle());
    }

    public function store(StoreOrderRequest $request, CreateOrder $action): JsonResponse
    {
        $order = $action->handle(OrderData::fromRequest($request));

        return (new OrderResource($order))->response()->setStatusCode(201);
    }

    public function show(Order $order): OrderResource
    {
        Gate::authorize('view', $order);

        return new OrderResource($order);
    }

    public function update(UpdateOrderRequest $request, Order $order, UpdateOrder $action): OrderResource
    {
        return new OrderResource($action->handle($order, OrderData::fromRequest($request)));
    }

    public function destroy(Order $order, DeleteOrder $action): Response
    {
        Gate::authorize('delete', $order);

        $action->handle($order);

        return response()->noContent();
    }
}
```

## Review Focus

1. Multi-word entity (`PurchaseOrder`) — table `purchase_orders`, URI `purchase-orders`, route param `purchase_order`, `$this->route('purchase_order')`, `$purchaseOrder`. Binding must work end-to-end. → Task 2 `derives multi-word names`, Task 5 e2e on `PurchaseOrder`.
2. `int` field posted as a form string (`"5"`) — Data must not throw `TypeError` under strict types. → Task 5 `accepts numeric strings`.
3. Nullable `Carbon\CarbonImmutable` sent as `null` and as an ISO string. → Task 1 mapping test + Task 5 e2e field `shippedAt:?Carbon\CarbonImmutable`.
4. `routes/api.php` with no `use` lines yet (fresh `make:module --api`) — `use` goes after `declare`. → Task 2 `adds use after declare when none`.
5. Second `make:crud` for a different entity in the same module — both routes and `use` lines present, first untouched. → Task 3 `adds a second entity`.
