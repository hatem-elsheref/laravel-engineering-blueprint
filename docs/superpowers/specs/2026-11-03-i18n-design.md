# Interface translations (i18n) — Design Spec

**Date:** 2026-11-03 · **Status:** Approved (owner chose "interface in several languages", not multilingual data). Calls below are the builder's.

## Goals
1. Every user-facing string in generated Blade pages, flash messages and the package's own HTTP messages goes through `__()` with English keys.
2. The package ships `lang/ar.json` for its own strings (loaded with `loadJsonTranslationsFrom`); apps override in `lang/ar.json`.
3. Locale per request — first match wins, only locales in `blueprint.locales` (default `['en']`):
   API requests (`expectsJson()`/`/api/*`): `Accept-Language` best match → web: `session('locale')` → `app.language` setting (saas/tenant-saas, when defined and a context exists) → `config('app.locale')`.
   Middleware `Best\Blueprint\Http\Middleware\SetLocale`, appended to the `web` and `api` groups.
4. Language switch: `GET /locale/{locale}` (name `blueprint.locale`, `web` group) stores the locale in the session and redirects back; unsupported → 404.
5. Layout: `<html lang dir>`; `dir="rtl"` for `blueprint.rtl_locales` (default `['ar','fa','he','ur']`); a switcher (links) when more than one locale is configured.
6. `make:crud --web` adds missing keys (entity headings, field labels, flash messages) to `lang/<locale>.json` for every configured locale except `en`, value = the English key ("translate me"), keeping existing values; prints `added <n> strings to lang/ar.json — translate them`.
7. Agent kit and docs: user-facing text must use `__()`; keys in English; translations in `lang/*.json`.

## Non-goals
Multilingual record content; translating Laravel's own validation messages (use `php artisan lang:publish` + a translation package — documented); locale in URLs.

## Tests
Locale resolution order and filtering; API header vs session; switch route (valid / unsupported / redirect back); RTL `dir`; package Arabic strings (`Edit` → `تعديل`, feature-disabled 403 message in Arabic for `Accept-Language: ar`); generated views/controller contain only translated strings (golden files); `make:crud` writes `lang/ar.json` keys without overwriting; end-to-end: Arabic page renders `dir="rtl"` and translated labels.
